# 202205307--Busqueda-del-tesoro
mi video juego se llama busqueda del tesoro; fue realizado en python. El objetivo es recorrer un mapa, superar obstaculos y encontrar el tesoro. el jugador cuenta con vidas y puntos, y puede moverse por diferentes direcciones. para realizar el juego se utilizaron clases como inventario y puntos, etc.
