# 202205307--Busqueda-del-tesoro
mi video juego se llama búsqueda del tesoro; fue realizado en python. El objetivo es recorrer un mapa, superar obstaculos y encontrar el tesoro. el jugador cuenta con vidas y puntos, y puede moverse por diferentes direcciones. para realizar el juego se utilizaron clases como inventario y puntos, etc.

# fase 1 Análisis
El video juego "Búsqueda del tesoro" permite poner en practica los conocimientos aprendidos en Python, especialmente el uso de clases, herencias, variables y condicionales. Durante el juego, el jugador debe tomar decisiones para avanzar y conseguir el tesoro sin perder todas sus vidas, ayuda a comprender de manera practica como funciona un programa
